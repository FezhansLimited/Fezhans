# Fezhans Agency Website

High-impact agency website for **Fezhans**, built for websites, custom web & mobile apps, and digital marketing.

## 🚀 Automatic Deployment with GitHub & Vercel

This repository is configured for automatic continuous deployment with **Vercel**. Every time changes are pushed to GitHub, Vercel automatically deploys the updated site live.

### Quick Setup Steps:
1. Create a repository on [GitHub](https://github.com/new) named `fezhans-agency-website`.
2. Push this project code to GitHub.
3. Import the repository at [Vercel New Project](https://vercel.com/new).
4. Vercel will automatically build and deploy your site.
5. Any future edits saved or committed to GitHub will trigger an instant automatic deployment on Vercel!
